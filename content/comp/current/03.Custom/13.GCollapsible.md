# GCollapsible

## 1. 구성요소

### 필수 속성

- title : Collapsible 의 제목

### 선택 속성

- type : header 의 색상 변경 가능함.(기본값 : gof)
- variant (solid | subtle | outline | soft): header 의 유형을 변경가능함. ( 기본값 : outline)
- innerIndent `number` : 본문 들여쓰기, 시스템 기본값은 4 임
- textSize ( xs| `sm`| md| lg) : 본문 글자크기 , 시스템 기본값은 sm

### 자식 Slot

- Default Child : Collapsible 의 본문

## 3. 설정 팁

- 기본설정 하단의 GCollapsible 은 전체 폭을 차지하고 있음.
- 글자크기 조정 예시 하단의 GCollapsible 은 리스트 문단과 같은 크기의 들여쓰기가 적용되어 있음.
- 두 들여쓰기 차이는 상위 요소 설정의 차이 때문임. GCollapsible 요소가 리스트 문단의 하위 요소인지 여부에 따라 들여쓰기가 달라짐.
- GCollapsible 요소 작성시 `::` 를 탭, 공백없이 작성하면 최상위 요소를 부모로 지정함..
- GCollapsible 요소 작성시 `::` 를 탭, 공백으로 리스트 문단보다 들여쓰기를 많이 하면 리스트 문단 요소를 부모로 지정됨.
- Editor 에 따라 여백 줄이 추가되어 있으면 자동으로 최상위 요소를 부모로 지정하기 위해 탭, 공백을 삭제하기 도 함.
- Editor 에 따라 여백 줄이 없으면 자동으로 바로 위 문단의 요소를 부모로 지정하기 위해 탭, 공백을 지정하기도 함.
- 작성중인 `VS Code` 에서는 여백 줄이 없으면 자동으로 바로 위 문단을 부모로 지정하고 있으며, 여백 줄이 있는 경우는 사용자가 입력한 탭, 여백을 그대로 남겨두고 있음.
- 작성중인 `VS Code` 에서는 부모 요소를 표시하기 위해 `세로 줄` 가이드가 표시되므로 참조해서 작성하면 됨.
